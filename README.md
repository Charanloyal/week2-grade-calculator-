# Student Grade Calculator (Week 2)

A Python program to manage student grades. It allows users to add students, calculate averages, assign grades automatically, and save the results to a file.

## 🚀 Features
* **Input Validation:** Ensures marks are between 0-100 and inputs are numbers.
* **Automatic Grading:** assigns A, B, C, D, or F based on average marks.
* **Search System:** Find a specific student by name.
* **File Handling:** Save all student records to `results.txt`.
* **Interactive Menu:** Easy-to-use text interface.

## 🛠️ How to Run
1.  Ensure Python is installed.
2.  Run the script in your terminal:
    ```bash
    python grade_calculator.py
    ```

## 📊 Grading Logic
* **A:** 90 - 100
* **B:** 80 - 89
* **C:** 70 - 79
* **D:** 60 - 69
* **F:** Below 60
